========== 一、详细描述（约 700 字符，要求 250–10000）==========

Pubmed IF Tag 在 PubMed 和 PMC 的搜索结果页、文章详情页自动标注期刊影响因子（IF）、JCR 分区与中科院分区，让你不必离开页面就能快速判断一篇文献的分量。

主要功能：

- 自动徽章：PubMed / PMC 每条引用行末尾追加按 IF 等级着色的「IF xx.x (Qx)」徽章，同时给出中科院大类分区。
- 颜色分级：IF≥20 深墨绿、≥10 中绿、≥5 柔麦黄、≥3 暖陶橙、低于 3 暗紫褐，阈值可自行调整。
- 点击复制：点一下徽章即可把「期刊全称 + IF + 分区」复制到剪贴板，写综述时直接粘贴。
- 筛选条：可按 IF 区间、JCR 分区（Q1–Q4）、中科院分区（1–4 区、Top）筛选，并把筛选结果导出为 CSV。
- 悬停卡片：鼠标悬停徽章可查看期刊全称、精确 IF、JCR 分区、中科院分区与数据版本。
- 内置 13575 本期刊，数据来自 JCR 2025 与中科院期刊分区表 2025，覆盖 PubMed 上出现的 SCIE 期刊，含神经科学、临床各科、肿瘤、免疫、药理、公共卫生，以及 Nature、Science、Cell 等综合刊。
- 按需更新期刊库：三个数据源（GitHub API、jsDelivr CDN、GitHub Raw）自动回退，也可一键恢复内置库，无需重装。
- 设置页：可开关标注、隐藏分区标签、调整颜色阈值、切换紧凑样式。
- 本地且注重隐私：不申请 tabs、history、webRequest、cookies 权限，无统计、无广告、无追踪，数据仅存本机，卸载即清除。
- 兼容 PubMed React 单页应用：翻页、切换搜索条件不刷新页面也能自动标注。

免费、开源（MIT 许可）。仅用于快速文献筛选，正式场合请以期刊官方数据为准。
