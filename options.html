设置

改动保存后，刷新 PubMed 页面生效

显示位置

搜索结果页
在文献列表的引用行后面标注 IF
文章详情页
在单篇文章页的期刊引用处标注 IF

标签外观

显示分区
标签里附带 Q1/Q2；关掉只显示 IF 数值
显示中科院分区
标签里附带中科院大类分区（1-4 区，2025 版）；关掉只保留 JCR 分区
紧凑样式
更小的标签、去掉底色，适合列表排版拥挤时
颜色分级阈值
IF 达到对应数值时的颜色：深墨绿 / 中绿 / 柔麦黄 / 暖陶橙。须按从大到小填写；最低档不低于 3 分，低于 3 分（不含）统一算「其他」

反馈

缺失时提示反馈
详情页遇到查不到 IF 的期刊时，在旁边显示一个小问号，点一下就能反馈这本刊
设置只存在本机（chrome.storage.local），不上传。
